# HTTP Module

It is built in Node.js Module which allows Developers to create web servers and
web client without installing any external package.

One of the most important module in Node.js,originally designed for buildiing
scalable network application and web servers.

1.Create web servers
2.Handle Client request
3.Build REST APIs
4.Non-Blocking I/0
5.Foundation of Express.js

#http-Hyper text transfer protocol

200-OK
201-Created
404-Not found
500-

npm->node package manager
manager->install,Uninstall

npm init -y = project biolerprite
npm i <package Name>=install any package
npm uninstall <Package Name>=uninstall
npm start

-200=ok
-201=created
-400=Bad request
-401=Unauthorized
-403=forbidden
-404=not found
-500=Internal Server Error
